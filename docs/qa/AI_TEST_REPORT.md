## 1. Gemini AI Integration Architecture

MilestonePay AI leverages Google Gemini 2.5 Flash as an intelligent co-pilot for freelance project structuring and objective deliverable verification:

```
[Unclear Project Description]
              │
              ▼
   Prompt & Constraints Builder
              │
              ▼
    Google GenAI SDK (gemini-2.5-flash)
    Structured JSON Schema Enforcement (GeminiProjectAnalysisSchema)
              │
              ├─ Project Summary & Complexity
              ├─ Assumptions & Clarifying Questions
              ├─ Risks & Clarification Flag
              └─ Sequenced Milestones
                    ├── Deliverables
                    ├── Acceptance Criteria
                    ├── Duration (Days)
                    └── Exact Budget Percentage (Sums to 100%)
              │
              ▼
   Backend Financial & Dependency Validator
              │
              ▼
   PostgreSQL Draft Milestone Plan (pending_approval)
```

### Key AI Safety Guardrails
1. **Advisory Status**: Gemini evaluations are strictly advisory. The AI cannot approve deliverables, release funds, or modify agreed milestones. Only the human client can authorize approval.
2. **Exact Cent Financial Allocation**: Percentages generated by Gemini are validated to sum to 100.0%. The backend computes exact monetary cent values for each milestone, guaranteeing zero rounding leakage.
3. **Structured Pydantic Validation**: All responses are parsed and validated against `GeminiProjectAnalysisSchema` or `GeminiDeliverableEvaluationSchema` before touching the database.
4. **Deterministic Settings**: Configured with low temperature (`0.2` for decomposition, `0.1` for deliverable evaluation) for consistent, objective analysis.

### 2.2. Evaluation Criterion States
The deliverable evaluation system enforces 4 objective statuses:
- `met`: Concrete evidence directly proves fulfillment of acceptance criterion.
- `partially_met`: Evidence demonstrates partial progress but incomplete scope.
- `not_demonstrated`: No uploaded artifact supports the claimed deliverable.
- `unable_to_assess`: File formats or external systems cannot be evaluated statically.
